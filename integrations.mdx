## API Integration

For custom integrations, use our REST API.

<Tabs>
  <Tab title="Webhooks" icon="webhook">
    Receive real-time updates from connected platforms.
    
    <CodeGroup tabs="JavaScript,Python">
      ````javascript
      app.post('/webhook/careerescaoe', (req, res) => {
        const { event, data } = req.body;
        if (event === 'job_applied') {
          updateRoadmap(data);
        }
        res.sendStatus(200);
      });
      ````
      ````python
      from flask import Flask, request
      
      app = Flask(__name__)
      
      @app.route('/webhook', methods=['POST'])
      def webhook():
        event = request.json['event']
        if event == 'skill_updated':
          process_skill_update(request.json['data'])
        return 'OK', 200
      ````
    </CodeGroup>
  </Tab>
  <Tab title="OAuth" icon="lock">
    Secure API access for third-party applications.
    
    <Expandable title="OAuth Flow" default-open="false">
      1. Redirect user to CareerEscape authorization URL
      2. User grants permissions
      3. Receive authorization code
      4. Exchange code for access token
      5. Use token for API calls
    </Expandable>
  </Tab>
</Tabs>

## Security and Privacy

All integrations use industry-standard security protocols.

<Callout kind="danger">Only grant necessary permissions to maintain data privacy.</Callout>

<Request tabs="Create Integration" show-lines="true">
  ````bash
  curl -X POST https://api.careerescaoe.com/v1/integrations \
    -H "Authorization: Bearer YOUR_TOKEN" \
    -H "Content-Type: application/json" \
    -d '{
      "platform": "linkedin",
      "permissions": ["profile", "network"],
      "sync_frequency": "daily"
    }'
  ````
</Request>

## Troubleshooting Integrations

Common issues and solutions.

| Issue | Solution |
|-------|----------|
| Connection failed | Check API credentials and network connectivity |
| Data not syncing | Verify sync settings and permissions |
| Rate limit exceeded | Implement exponential backoff for API calls |

## Best Practices

- Start with one integration at a time
- Test thoroughly in development environment
- Monitor API usage to avoid rate limits
- Keep integration credentials secure
- Regularly review and revoke unnecessary permissions

<Callout kind="success">Well-configured integrations can improve roadmap accuracy by up to 60%.</Callout>
